Manual para editar y publicar una pagina web

  1. Crear la carpeta en el nuestro disco duro, trabajar en local.
  2. Abrir en programa Visual Studio Code, arrastrar la carpeta al explorador o open folder
  3. Crear new file: index.html
  4. Editar el fichero
  5. Abrir el navegador y acceder a nuestro perfil de github >
  6. Crearemos un repositorio p1
  7. Add files i upload files
  8. Una vez que el archivo index.html aparece en el directorio del nuestro repositorio, iremos a settings, en la barra de la izquierda, busques pages y en github pages cambias el none a main y apretes save
  9. Espereamos un poco y actualizaremos y aparecera
